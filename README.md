# Time-Series-Analysis-with-Cryptocurrency
# 📈 Cryptocurrency Analytics Dashboard

A dynamic and interactive cryptocurrency analytics dashboard built using [Streamlit](https://streamlit.io?utm_source=chatgpt.com), [Plotly](https://plotly.com/python/?utm_source=chatgpt.com), and Machine Learning models like ARIMA and LSTM for cryptocurrency price prediction.
The dashboard provides real-time style visualization, prediction comparison, volatility tracking, sentiment analysis, and performance metrics in a user-friendly interface.

# 🎯 Objectives of the Project

The main objectives of this project are:

1. To analyze historical cryptocurrency market data.
2. To visualize price trends and market behavior interactively.
3. To compare different forecasting models such as ARIMA, LSTM, and Prophet.
4. To measure prediction accuracy using RMSE.
5. To study volatility and sentiment trends in cryptocurrency markets.
6. To create a user-friendly analytics dashboard for financial data visualization.

# 📌 Key Concepts Used

## ARIMA

A statistical time-series forecasting model used for trend prediction.

## LSTM

A deep learning neural network model designed for sequential/time-series data.

## Prophet

A forecasting model developed for handling seasonal time-series data.

## RMSE

Root Mean Square Error — used to measure prediction accuracy.

RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
